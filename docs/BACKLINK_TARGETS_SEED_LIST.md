## Usage Rules

- Validate current contact paths before outreach.
- Personalize each request to an existing published article, report, event, or resource page.
- Ask for contextual editorial links only, never paid or reciprocal links.
- Prefer one specific destination URL per outreach message.
- Record all sends and outcomes in the monthly tracker.

## Weekly Execution Cadence

- Monday: 5 personalized sends (mix: 2 editorial, 2 institutional, 1 government/community).
- Wednesday: 5 personalized sends.
- Friday: one follow-up wave for messages sent 7-10 business days earlier.
- Month-end: summarize reply rate, conversion rate, and retained links.
